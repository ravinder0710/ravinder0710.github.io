2. Global Retail Sales & Profit Analysis Microsoft Excel • Power Pivot • DAX • Power Query • Star Schema

  • Analyzed 606 products and identified 448 (74%) had no sales; isolated that products priced >$150 generated $120.5M in profit (95.4% of total).
  • Replaced VLOOKUP formulas with DAX measures and engineered a 2-page dashboard with interactive slicers and macro reset controls.
3. Customer Churn Analysis Python • Pandas • NumPy • Seaborn • EDA

  • Isolated ~27% churn (2,727 customers) risking ~$73K monthly revenue; identified highest churn concentration in month-to-month contracts under 12 months.
4. Bank Loan Analytics MySQL • Power BI • Python • Tableau • DAX
