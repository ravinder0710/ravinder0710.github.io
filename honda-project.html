[ problem ] · § as found

Nationwide dealership networks relied on manual end-of-day Excel spreadsheet exports, creating 48-to-72 hour reporting latencies. Regional sales directors had no live visibility into high-demand model stockouts, showroom turnaround velocity, or dealer financing attachment trends.

Enterprise ETL platforms (Fivetran, Talend) carried prohibitive monthly subscription costs for non-enterprise dealership tiers. The business required an enterprise-grade automated pipeline operating on serverless, zero-maintenance infrastructure.

constraints & technical boundaries

  • Zero-Cost Cloud Infrastructure: Build complete pipeline utilizing free-tier serverless PostgreSQL (Neon) and n8n cloud automation without recurring licensing fees.
  • Sub-Second DirectQuery Latency: Power BI connects live to analytical PostgreSQL views without import mode caching delays, requiring indexed join execution.
  • Automated Data Cleansing & Ingestion: n8n webhook listener parses incoming dealership CSV feeds, validates schema constraints, deduplicates chassis IDs, and stages clean tables.
  • Intraday Inventory Rebalancing: Provide actionable dealership-level sales velocity metrics to compress regional warehouse holding cycles from 38 days to 24 days.

[ relational engineering ] · production dax & staging queries

Production DAX measures engineered to calculate gross showroom revenues and isolate model volume shares under DirectQuery mode:

// 1. Gross Showroom Sales Revenue Across 5,617 Vehicle Records
Total Revenue (INR) = 
SUMX(
    fact_sales,
    fact_sales[units_sold] * fact_sales[unit_price_inr]
)

// 2. Activa 6G Volume Contribution % (Steers Dealer Restocking)
Activa 6G Volume Share = 
DIVIDE(
    CALCULATE(SUM(fact_sales[units_sold]), dim_model[model_name] = "Activa 6G"),
    CALCULATE(SUM(fact_sales[units_sold]), ALL(dim_model)),
    0
)

// 3. PostgreSQL Analytical Staging View (Pushed from DirectQuery)
CREATE OR REPLACE VIEW vw_dealership_sales_summary AS
SELECT 
    d.dealer_id,
    d.region_name,
    m.model_name,
    m.segment_type,
    s.sale_date,
    s.units_sold,
    (s.units_sold * m.ex_showroom_price) AS gross_revenue_inr
FROM fact_dealership_sales s
JOIN dim_dealers d ON s.dealer_id = d.dealer_id
JOIN dim_vehicle_models m ON s.model_id = m.model_id;
