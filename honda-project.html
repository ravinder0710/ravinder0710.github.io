End-to-End Cloud Pipeline Architecture

Zero-Cost Cloud Data Flow Architecture

How dealership raw telemetry is ingested, cleansed, normalized into serverless Neon PostgreSQL, and piped directly into Power BI via DirectQuery with zero monthly infrastructure overhead.

1
Raw Telemetry Ingestion

Multi-source dealership CSV logs recording transactional timestamps, engine chassis IDs, ex-showroom invoices, and financing modes.

2
n8n Workflow Automation

Cloud webhook triggers n8n workflow for automated data cleansing, deduplication, schema validation, and SQL staging insertion.

3
Neon PostgreSQL Database

Normalized relational tables with indexing on `dealer_id`, `model_id`, and `sale_date`. Dedicated analytical views optimized for live BI querying.

4
Power BI DirectQuery

Zero import caching latency. Power BI pushes DAX queries directly as optimized SQL to Neon PostgreSQL with sub-second query response.

Production DAX Time-Intelligence & Share Measures

Calibrated analytical measures engineered for DirectQuery execution without performance degradation.

1. Total Revenue (Ex-Showroom) Aggregated DAX 
Total Revenue = 
SUMX(
    fact_sales,
    fact_sales[units_sold] * fact_sales[unit_price_inr]
)

Calculates exact INR gross sales volume across all 5,617 transactional records.

2. Activa 6G Volume Contribution % Share % DAX 
Activa 6G Volume Share = 
DIVIDE(
    CALCULATE([Total Units], dim_model[model_name] = "Activa 6G"),
    CALCULATE([Total Units], ALL(dim_model)),
    0
)

Isolates Activa 6G as the 38.4% volume driver to steer dealership restocking quotas.
